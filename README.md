## 💻 Recommended Clients by Platform

> 📌 **Note on Subscription Formats:**  
> Native V2Ray / Sing-box clients (like **Hiddify**, **v2rayNG**, **NekoBox**, **Husi**, **Shadowrocket**, **FoXray**) import raw link subscriptions (`vless://`, `vmess://`, Base64) natively.  
> Clash-based GUIs (like **Clash Verge Rev** or **Stash**) use built-in **subconverters** to parse raw V2Ray links into Clash YAML format automatically upon import.

## 📖 How to Use

1. Copy your preferred subscription link from the tables above.
2. Open your client of choice (e.g., *Hiddify*, *v2rayN*, *v2rayNG*, *Shadowrocket*, *Husi*).
3. Select **Add Profile / Import Subscription from Clipboard**.
4. Update/refresh subscriptions within your client to automatically fetch the latest low-latency nodes.
